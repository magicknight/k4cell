# K4 Cell support surface

`index.html` is the bilingual public contact page for research patronage,
institutional sponsorship, strategic collaboration and separately recorded
future K4V interest.

The live state is deliberately `CONTACT_ONLY`. The page accepts no payment,
wallet address, token order, investment subscription or promised return.
`SUPPORT_STATUS_v0.1.json` is the machine-readable form of that boundary.
The on-page roadmap is the public compression of
`docs/COMMUNICATION_AND_SUPPORT_ROADMAP_v1.md`.

When any transaction channel is later authorised, update the page and status
file together, add the relevant legal and governance documents, and make the
new state pass the site integrity checks before publication.
